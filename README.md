# API de Productos y Estudiantes

API REST desarrollada en Flask con SQLite, sistema de caché (Cache-Aside) e integración de CORS. Documentada interactivamente con Swagger.

## Instalación y Ejecución

1. Clonar el repositorio.
2. Crear un entorno virtual: `python -m venv .venv`
3. Activar el entorno virtual: `.\.venv\Scripts\activate` (Windows)
4. Instalar dependencias: `pip install -r requirements.txt`
5. Ejecutar la API: `python app.py`

La documentación de Swagger estará disponible en: `http://localhost:5000/apidocs/`
